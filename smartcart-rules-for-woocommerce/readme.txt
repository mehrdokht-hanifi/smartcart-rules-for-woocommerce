Configurable payment-method discounts, tiered cart rewards, and free-shipping thresholds for WooCommerce.

== Description ==

SmartCart Rules lets store managers configure automatic cart discounts for selected payment methods and make existing shipping rates free after defined thresholds.

Features include five percentage or fixed-amount discount tiers, coupon policy, product and category exclusions, shipping-rate matching, progress notices, and HPOS-compatible order metadata.

Version 1.0.1 supports classic WooCommerce Cart and Checkout pages. Cart and Checkout Blocks are not currently supported.

== Installation ==

1. Upload and activate the plugin.
2. Open WooCommerce > SmartCart Rules.
3. Configure eligible gateways, tiers, and shipping rules.
4. Verify every rule on a staging store before production use.
